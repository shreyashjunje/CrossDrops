# Built on 2026-11-02 (Phase 1)

Short summary of what exists after the first day. Details: [features/file-transfer-poc.md](features/file-transfer-poc.md).

## Built

- **Receiver (HTTPS server):** random port, per-launch self-signed certificate.
  - `POST /v1/sessions` starts a transfer (auto-accepted in Phase 1).
  - `PUT ...?offset=N` streams bytes into a `.part` file.
  - `GET` returns `receivedBytes`.
  - `POST .../complete` checks SHA-256, then saves under a sanitized name.
- **Sender (HTTPS client):** streams 1 MB chunks, shows progress and MB/s (3-second average).
- **Stop and Resume:** continues from the receiver's byte count, nothing is sent twice.
- **Stall handling:** the upload fails after 15 s without progress, so a Wi-Fi drop does not hang the app.
- **Integrity:** SHA-256 computed in a background isolate on both sides; a wrong hash is never saved.
- **Safety checks:** file names sanitized (no paths, control characters or reserved names); bytes beyond the declared size are rejected.
- **Screens:** Home, Receive (IP, port, progress, save folder) and Send (IP, port, file picker, Send/Stop/Resume, MB/s).
- **PC test tool:** `tool/crossdrop_cli.dart` receives from or sends to a phone, using the same core code. Dev tool only.
- **Setup:** Android `INTERNET` permission, iOS local network text and Files access, Android NDK 28.2 installed.

## Tested

- 47 unit tests pass on the PC, including a 50 MB loopback transfer with matching hash, a memory check (peak growth 17-20 MB) and kill-halfway resume.
- Samsung (Android 13) to PC over Wi-Fi: a 1.2 MB video arrived and the SHA-256 was verified.

## Not done yet

- iPhone: nothing built or tested (needs a Mac, or a cloud build plus sideloading).
- 100 MB and 1 GB transfers, speed numbers, Stop/Resume and Wi-Fi-drop recovery on a phone.
- Multiple files in one transfer (later phase).
- Discovery, QR code, Accept prompt, pinned TLS (later phases). The client accepts any certificate for now (D-011).
- Phase 1 is not complete until checks P1-1 to P1-7 pass on one iPhone and one Android phone ([DEVICE_TESTS.md](DEVICE_TESTS.md)).
